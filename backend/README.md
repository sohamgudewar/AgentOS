# AgentOS

Enterprise AI Command Center

A production-ready platform for building, deploying, governing, and monitoring enterprise AI agents using LangGraph, MCP, Enterprise RAG, and Human-in-the-Loop workflows.

## Tech Stack

- FastAPI
- Next.js
- LangGraph
- PostgreSQL
- Redis
- Qdrant
- Docker
- Azure

Status: 🚧 Under Development

We'll follow this workflow throughout AgentOS:

Build a complete module
        ↓
Run it
        ↓
Fix bugs
        ↓
Commit
        ↓
Move to the next module

This avoids debugging incomplete code and keeps the project in a working state after every major milestone.
